## 1. Core message
For 3D printing hobbyists, Meshy 3D Agent turns ideas into print-ready models through chat by creating and editing models, checking and fixing issues, and helping with print prep.

## 2. 3D agent vs. existing UI
Meshy’s image and model tools already generate 3D assets. In the existing UI, users provide references and choose settings for individual tasks. With the 3D agent, they describe what they want, and it uses their references and earlier choices to do the work.

The change is from one-shot generation to an ongoing, iterative workflow. Users can explore ideas, request edits, generate models, and troubleshoot issues in the same chat without figuring out which tool to use for every action. They still choose the direction, review results, and approve actions.

## 3. Launch plan

I would prioritize these five actions. With limited resources, I’d learn from hobbyists and activate existing users before expanding acquisition. Some activities can run in parallel.

### 1. Test the message and workflow with qualified hobbyists
**Purpose:** Observe hobbyists taking an idea through creation and printing prep. Understand why they choose the 3D agent, where they need help, and whether the page sets the right expectations. Include physical printing in a small group.
**Expected impact:** Sharpen the message, identify adoption barriers, and collect launch examples.
**Partners:** PMM leads research, with Product and Support investigating issues.

### 2. Define the launch funnel and success measures
**Purpose:** Track users from the landing page through project start, model generation, printability checks, and file download or direct slicer export. Separate new-user acquisition from existing-user adoption.
**Expected impact:** Identify drop-offs and focus effort on the relevant step of the customer’s journey.
**Partners:** PMM defines success; Product and Engineering support tracking.

### 3. Create more show-and-tell assets
**Purpose:** Create short videos, before-and-after examples, and documented projects showing edits, repairs, and printing prep.
**Expected impact:** Show the value beyond generation across launch channels.
**Partners:** PMM owns the story and messaging, working with Design, Content, and Product.

### 4. Activate relevant existing Meshy users
**Purpose:** Use targeted email and in-product messaging to explain when to choose the 3D agent over the Image and Model tools. Use available printing-interest signals, such as printability checks or slicer exports.
**Expected impact:** Help existing users choose the 3D agent for their next printing project.
**Partners:** Marketing/Growth supports email, and Product supports in-product targeting and delivery.

### 5. Engage 3D printing communities and creators
**Purpose:** Work with creators and community members to document projects through finished prints, including troubleshooting.
**Expected impact:** Reach qualified hobbyists, build confidence, and understand objections before expanding acquisition.
**Partners:** Community and creator relationships team.

I would defer broad paid acquisition and a large asset library until we know which message drives adoption and where users get stuck.

## 4. Measurement and experimentation
I would track:
- **3D agent activation rate:** Percentage of new users from launch channels who complete a follow-up action within seven days of signup, such as a design revision, reference-image edit, or printability check. This measures use beyond initial generation; validate the window with Product.
- **Print-export rate:** Percentage of activated users who download an STL/3MF or send a model directly to a slicer. This signals intent to print; validate successful slicing and printing through user follow-up.
- **Week-2 return rate:** Percentage of activated users who start a second distinct project on days 8–14 after signup. This indicates repeat value beyond curiosity.

Agree targets and measurement windows with Product using available data, tracking existing users separately.

**Why these, not others:** These measure workflow adoption, progress toward printing, and repeat value. Other metrics like Sign-ups measure acquisition, whereas prompt and generation counts alone don’t establish value.

**First A/B test**


**Hypothesis:** Wanting a model they can’t find to download may be a stronger reason to try the 3D agent than the broader workflow promise, leading to more print exports.


**Variable:** Change only the hero headline. Keep the supporting copy, demonstration, and CTA unchanged:  
**A:** “From idea to print-ready model in one conversation.”  
**B:** “Can’t find the model you want to print? Create it in one conversation.”


**Metric:** Visitor-to-print-export rate: percentage of assigned visitors who download an STL/3MF or send a model directly to a slicer within an agreed window.

**Threshold:** Proposed win: at least 15% relative lift for B, with 95% confidence the improvement is positive, without reducing sign-up conversion by more than 10% relative. A statistically clear export decline or confirmed sign-up decline beyond that limit is a loss; otherwise, inconclusive. Agree on thresholds, sample size, and duration before testing.

**Why it matters:** If B wins, lead with creating models users can’t find; if A wins, retain the broader workflow message. Review first prompts and follow up with users to understand the result.

## 5. Trade-offs
**Depth over breadth:** I chose one garden figurine project over a broad feature tour. Skills get less space, but users see concepts, edits, generation, repairs, and slicer preparation.

**Evidence over polish:** I used actual responses and screenshots, including the additional Bambu repair. The page labels the condensed demo and reports successful slicing without claiming a physical print.
